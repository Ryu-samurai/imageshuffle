使い方

「画像しゃっふる」は、パスワードを使って画像をランダムに並び替え(シャッフル)し、同じパスワードで元通りに並び替え直す(復元)ことができるアプリです。

シャッフルした画像は、シャッフル時に使ったパスワードを入力しないと元に戻せません。パスワードは忘れないよう、大切に管理してください。

1. 画像を選択する

  1. 「画像を選択」ボタンをタップします。
  2. 端末内のギャラリーから、処理したい画像を選びます。
  3. 選択すると画像が画面上部にプレビュー表示されます。
以前このアプリで保存した「シャッフル済み」や「復元済み」の画像を選んだ場合、プレビューには専用のアイコン画像が表示されます(画像そのものが乱れて見えてしまうのを防ぐためです)。中身は正しく読み込まれていますので、そのまま操作を続けて問題ありません。

2. モードを選ぶ

「モード」欄で、以下のどちらかを選択します。

モード内容
シャッフル選択した画像を、パスワードをもとにランダムな並び順に変換します。
復元シャッフル済みの画像を、パスワードをもとに元の並び順に戻します。

3. 設定を行う

パスワード

  • 「パスワード」欄に、シャッフル・復元に使う文字列を入力します。
  • 復元したい場合は、シャッフル時に入力したものと同じパスワードを入力する必要があります。
  • 右側の「保存」にチェックを入れておくと、次回アプリ起動時にパスワードが自動的に入力された状態になります。毎回入力する手間を省きたい場合にご利用ください。
チェックを入れた場合、パスワードは端末内に保存されます。他の人と端末を共有している場合はご注意ください。

画像サイズ(シャッフル時のみ)

  • 元サイズ:読み込んだ画像そのままのサイズでシャッフルします。画像によっては処理に時間がかかる場合があります。
  • 縮小(高速):画像を縮小したうえでシャッフルします。処理が速くなり、保存後のファイルサイズも小さくなります。

この設定は「復元」モードを選んでいるときは使用しないため、灰色表示になり選べません。

4. 実行する

  1. 画像・モード・パスワードの入力が済んだら、「▶ 実行する」ボタンをタップします。
  2. 処理中は画面に「処理中...」の表示が出ます。そのままお待ちください。
  3. 処理が終わると、「結果プレビュー」欄に変換後の画像が表示されます。
画像を選択していない場合、またはパスワードが未入力の場合、「実行する」ボタンを押しても何も起こりません。まずは画像の選択とパスワードの入力を確認してください。

5. 結果を保存・やり直す

  • 保存する:結果プレビューの画像を、端末のギャラリー(アルバム内の「Shuffle」フォルダ)に保存します。ファイル名の先頭には、シャッフルなら「shuffled_」、復元なら「restored_」が付き、日時が記録されます。
  • 再実行:同じ設定のまま、もう一度実行します。
結果プレビューに表示されている画像をタップすると、画像ビューワーが開いて画面いっぱいに拡大表示されます。指でつまむような操作(ピンチ操作)で、さらに拡大・縮小して細部まで確認できます。
※この拡大表示は「結果プレビュー」の画像でのみご利用いただけます。手順1で選択した画像のプレビューではご利用いただけません。

6. 画像を人に送る・SNSに投稿するときの注意

シャッフルした画像を元に戻す(復元する)には、シャッフルしたときに保存されたPNG形式の画像ファイルそのものが必要です。

LINEやX(旧Twitter)、Instagramなどで画像を「写真」として送信・投稿すると、送っている間に画像が自動的に小さく加工されたり、別の形式に変換されたりすることがあります。そうなった画像は、たとえ見た目が同じでも元に戻すことができなくなります。

同じ理由で、画面をスクリーンショットして保存した画像も復元できません。

  • 元に戻せる状態を保ちたい場合は、シャッフル後に保存されたPNGファイルを、そのまま(写真としてではなく)「ファイル」として送るようにしてください。例えばLINEなら「アルバム」ではなく「ファイル」を選んで送信します。
  • メールの場合は、画像を本文に貼り付けるのではなく、添付ファイルとして送ってください。
  • 大切な画像は、送信・投稿する前に必ず元のPNGファイルを端末やクラウドなどに保管しておくことをおすすめします。

7. メニュー(☰)について

画面右上の「☰」ボタンをタップすると、以下の項目が表示されます。

  • 使い方:簡単な使い方の説明が表示されます。
  • プライバシーポリシー:個人情報の取り扱いについて確認できます。
  • アプリ情報:バージョン情報や開発者情報、お問い合わせ先を確認できます。

How to Use

"Image Shuffle" is an app that uses a password to randomly rearrange (shuffle) the pixels of an image, and can restore the original arrangement (restore) using the same password.

A shuffled image can only be restored by entering the same password that was used to shuffle it. Please keep your password safe and don't forget it.

1. Select an Image

  1. Tap the "Select Image" button.
  2. Choose the image you want to process from your device's gallery.
  3. Once selected, the image is shown as a preview at the top of the screen.
If you select an image that was previously "shuffled" or "restored" and saved by this app, the preview will show a dedicated icon instead of the image itself (this is to prevent the scrambled image from being confusing to look at). The file is still loaded correctly, so you can continue as normal.

2. Choose a Mode

In the "Mode" field, select one of the following.

ModeDescription
ShuffleConverts the selected image into a random pixel arrangement based on the password.
RestoreRestores a previously shuffled image to its original arrangement based on the password.

3. Configure Settings

Password

  • Enter the string you want to use for shuffling/restoring in the "Password" field.
  • To restore an image, you must enter the same password that was used when it was shuffled.
  • Checking "Save" on the right will automatically fill in the password the next time you open the app, so you don't need to type it every time.
If you enable this option, the password will be stored on your device. Please be cautious if you share your device with others.

Image Size (Shuffle mode only)

  • Original size: Shuffles the image at its original loaded size. Processing may take longer depending on the image.
  • Downscale (fast): Shuffles the image after downscaling it. Processing is faster and the resulting file size is smaller.

This setting is not used in "Restore" mode, so it appears grayed out and cannot be selected.

4. Run

  1. Once you've selected an image, mode, and entered a password, tap the "▶ Run" button.
  2. A "Processing..." indicator will appear while the operation runs. Please wait.
  3. When finished, the converted image will appear in the "Result Preview" area.
If no image is selected, or the password field is empty, tapping "Run" will do nothing. Please make sure you've selected an image and entered a password first.

5. Save or Retry

  • Save: Saves the resulting preview image to your device's gallery (in a "Shuffle" folder within your albums). Filenames are prefixed with "shuffled_" for shuffle results or "restored_" for restore results, along with a timestamp.
  • Retry: Runs the operation again with the same settings.
Tapping the image shown in the Result Preview opens a full-screen image viewer, where you can take a closer look. You can pinch with two fingers to zoom in and out for more detail.
※ This full-screen viewer is only available for the Result Preview image. It is not available for the preview shown after selecting an image in Step 1.

6. Sharing Images or Posting to Social Media

To restore a shuffled image back to normal, you need the original PNG image file that was saved when it was shuffled.

If you send or post an image as a "photo" through apps like LINE, X (Twitter), or Instagram, the image may be automatically shrunk or converted to a different format while it's being sent. Once that happens, the image can no longer be restored, even if it still looks the same.

For the same reason, an image saved as a screenshot cannot be restored either.

  • To keep an image restorable, send the saved PNG file itself as a file, not as a "photo". For example, in LINE, choose "File" instead of "Album/Photos" when sending.
  • When emailing an image, send it as an attachment rather than pasting it into the body of the message.
  • For important images, we recommend always keeping a copy of the original PNG file on your device or in the cloud before sending or posting it anywhere.

Tapping the "☰" button in the top-right corner shows the following items.

  • Privacy Policy: View information on how personal data is handled.
  • App Info: View version information, developer information, and contact details.
